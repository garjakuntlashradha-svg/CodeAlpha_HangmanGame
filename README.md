# CodeAlpha Hangman Game

## About the Project
This is a simple word-guessing game developed using Python as part of my CodeAlpha Python Programming Internship.

## Features
- Random selection from five predefined words.
- Guess the hidden word one letter at a time.
- Maximum of six incorrect guesses.
- Input validation.
- Win and game-over messages.

## Technologies Used
- Python
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python hangman.py`.

## Python Concepts Used
- Lists and strings
- Random module
- While and for loops
- Conditional statements
- User input and output
